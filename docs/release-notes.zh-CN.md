# UXQA 更新说明

## UXQA 0.7.0

在本版下载页的 **Assets** 选择对应系统和芯片的压缩包，用 `SHA256SUMS.txt` 校验后解压。Mac 打开 `UXQA.app`，Windows 双击 `Open uxqa console.cmd`，Linux 运行 `./open-uxqa-console.sh`。更新前先退出旧版。[中文安装说明](install-and-use.md) · [English installation guide](install-and-use.en.md)

八类专项均可按规程保存任务验收案例和后续轮次复检。新增双人盲评、分歧裁定、项目级独立盲测、模型证据不足时暂缓判断，以及模型通过与参与者自评困难的对照。滚动、聚焦和悬停可在普通与减少动态效果模式下分别采样。 [使用方法与指标口径](assurance-workflows.md#给每道规程建立可复查的案例)

依据文档生成的检查会在编排和执行前两次校验显式预期，拦截未引用的文字、数量或目标地址，以及将同一个观测值与自己比较的用例。

各类检查可拖入多份文档、设计图、画板导出，或关联 Git 仓库与单个代码链接。导入保留版本和出处，线上读取与本地操作各有提示。模型设置新增 LM Studio 本机预设。[格式与联网说明](product-guide.zh-CN.md#导入检查依据)

检查台新增八类专项和 24 项验证程序。项目依据支持按条款关联多个类别，核对文件版本，并交给项目对话编排场景。新增设计稿 PNG 与本轮页面截图比对、页面专项实测和逐项验证记录。[运行方法](product-guide.zh-CN.md#通用逻辑检查)

「问题处理」会在滑动时保留搜索框和严重程度筛选。长列表自动加载，打开问题再返回时保留阅读位置。上下键可逐条浏览，Home / End 可跳到首末项。本轮预览失败时，可直接从提示打开预览地址设置。

## UXQA 0.6.1

项目对话与命令行共用通用逻辑检查。可依据项目文件或本次明确要求，跨操作、页面与角色采集命名观测，判断一致性、变化、数值边界和撤销后的状态。条件未触发或关键证据缺失会显示待验证。0.6.0 的清单场景仍可运行。[使用方法和示例](product-guide.zh-CN.md#通用逻辑检查)

## 0.6.0（本机构建）

项目修复对话和命令行加入分角色场景、操作前后清单快照、逐项比对和证据缺口记录。随附的期限与任务分配场景使用本地合成数据。

## 0.5.2

- 项目专属修复对话接入当前问题、截图、项目规则、组件目录与源码复检，支持直接修改项目文本并撤销。
- 对话可准备组件计划；核对脚本和浏览器场景并由用户启动后，验证通过才同步项目组件目录与规格。验证截图纳入 48 小时清理。
- 设计候选增加可追溯的本轮源码引用和语义变量；浏览器方案可比较多个现有元素并隔离本地状态；动效采样增加滚动、减少动态效果模拟和可用的主线程计数，实际覆盖范围见使用说明。
- 增加需先核对并由用户启动的代码方案比较：可临时替换页面加载的同源脚本或样式，比较实际结构与交互；不修改源码，需使用可信测试环境并在选择后实现和复检。
- 在对话中生成设计候选、打开临时浏览器方案比较，并采集或对比特定交互的浏览器帧回调。候选、源码检查和页面实测分别标记；浏览器预览、动效采样和自动检查均有明确覆盖限制。
- 真实账号、实际设备、所有页面状态和三个参考项目的完整等价性仍需分别验证。选择对应系统和芯片的下载包，并用同版本的 SHA256SUMS.txt 核对。

## 0.5.0

检查流程按项目、检查、问题处理和复检组织。内置质量规程参与问题分类、截图诊断和修复方案；增加网页结构、命名、标签与动效相关检查。方案支持逐项记录验证结果和证据，并保留处理历史。未执行的检查不算通过。

首次启动可选择中文或 English，逐步查看访问说明并检查项目目录；设置显示最近一次访问结果，支持重新检查。系统负责保存授权，授权或目录状态可能变化。历史结果、项目内容与服务商消息保留原语言。真实 macOS 授权变化以及各平台包应以对应验证结果为准。

本轮新增截图 48 小时保留策略，覆盖应用截图和已登记的命令行截图：应用运行时定期清理，关闭期间到期的截图在下次启动或命令行检查时清理；检查记录和手动另存的副本保留。旧自定义输出目录无法自动发现。

## 0.4.0 已发布版本

- macOS 14+：Apple Silicon 与 Intel 原生应用。
- Windows 11+ x64、Linux glibc x64/ARM64：便携包，使用本地浏览器界面。
- 模型协议、服务商配置和独立订阅账号管理内置于 UXQA，不需要启动其他应用。
- 项目组件检查、浏览器证据与可选 AI 截图复核；截图浏览器按确认后下载。
- 安装包、校验摘要、系统权限和本地数据说明见 [安装与使用](install-and-use.md)。

macOS 包采用临时签名，未经过 Apple 公证；Windows 包没有 Authenticode 签名。Windows ARM64 和 Linux musl 没有本版本原生包。不同系统策略、真实订阅账号和全部页面状态不能由自动构建结果代替验证。

下载实际发布的版本并核对 SHA256；退出应用并备份本地数据后再更新。Windows/Linux 更新时将新版解压到新目录，避免混合版本文件。
