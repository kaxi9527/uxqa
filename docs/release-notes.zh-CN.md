# UXQA 更新说明

## 0.5.2 开发版（尚未发布）

- 项目专属修复对话接入当前问题、截图、项目规则、组件目录与源码复检，支持直接修改项目文本并撤销。
- 对话可准备组件计划；核对脚本和浏览器场景并由用户启动后，验证通过才同步项目组件目录与规格。验证截图纳入 48 小时清理。
- 设计候选增加可追溯的本轮源码引用和语义变量；浏览器方案可比较多个现有元素并隔离本地状态；动效采样增加滚动、减少动态效果模拟和可用的主线程计数，实际覆盖范围见使用说明。
- 增加需先核对并由用户启动的代码方案比较：可临时替换页面加载的同源脚本或样式，比较实际结构与交互；不修改源码，需使用可信测试环境并在选择后实现和复检。
- 在对话中生成设计候选、打开临时浏览器方案比较，并采集或对比特定交互的浏览器帧回调。候选、源码检查和页面实测分别标记；浏览器预览、动效采样和自动检查均有明确覆盖限制。
- 真实账号、实际设备、所有页面状态和三个参考项目的完整等价性仍需分别验证。本次源码更新不提供新的安装包下载。

## 0.5.0

检查流程按项目、检查、问题处理和复检组织。内置质量规程参与问题分类、截图诊断和修复方案；增加网页结构、命名、标签与动效相关检查。方案支持逐项记录验证结果和证据，并保留处理历史。未执行的检查不算通过。

首次启动可选择中文或 English，逐步查看访问说明并检查项目目录；设置显示最近一次访问结果，支持重新检查。系统负责保存授权，授权或目录状态可能变化。历史结果、项目内容与服务商消息保留原语言。真实 macOS 授权变化以及各平台包应以对应验证结果为准。

本轮新增截图 48 小时保留策略，覆盖应用截图和已登记的命令行截图：应用运行时定期清理，关闭期间到期的截图在下次启动或命令行检查时清理；检查记录和手动另存的副本保留。旧自定义输出目录无法自动发现。

## 0.4.0 已发布版本

- macOS 14+：Apple Silicon 与 Intel 原生应用。
- Windows 11+ x64、Linux glibc x64/ARM64：便携包，使用本地浏览器界面。
- 模型协议、服务商配置和独立订阅账号管理内置于 UXQA，不需要启动其他应用。
- 项目组件检查、浏览器证据与可选 AI 截图复核；截图浏览器按确认后下载。
- 安装包、校验摘要、系统权限和本地数据说明见 [安装与使用](install-and-use.md)。

macOS 包采用临时签名，未经过 Apple 公证；Windows 包没有 Authenticode 签名。Windows ARM64 和 Linux musl 没有本版本原生包。不同系统策略、真实订阅账号和全部页面状态不能由自动构建结果代替验证。

下载实际发布的版本并核对 SHA256；退出应用并备份本地数据后再更新。Windows/Linux 更新时将新版解压到新目录，避免混合版本文件。
