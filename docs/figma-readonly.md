# Figma 只读检查

`uxqa figma` 检查 Figma 组件主件的设计数据。它通过现有 Figma Plugin API / MCP 连接读取，不包含登录、令牌存储、发布或修改设计操作。它不是把 Figma 编辑器网页当产品网页扫描，也不把静态图片当可交互 DOM。

## 采集与检查

先建立只包含当前授权页面的配置：

```json
{
  "fileKey": "yourFileKey",
  "pageId": "1:2",
  "themes": [
    { "name": "Light", "background": [1, 1, 1, 1] },
    { "name": "Dark", "background": [0.08, 0.08, 0.08, 1] }
  ]
}
```

主题名必须匹配相关变量集合的 mode 名。可使用 `backgroundVariableId` 绑定产品已有背景变量；解析失败会列为未验证，不回退到猜测颜色。显式 RGBA 背景是画布未设填充时的设计背景合同，必须取自该产品。

```sh
uxqa figma prepare --config /path/to/figma.json --out /path/to/new-capture
# 经现有 Figma 连接执行生成的 index.js，返回值原样保存为 index.json。
# 从 index.json 取组件 ID，仅替换 collect.js 中 UXQA_IDS 的数组；每批 1–30 个。
# 顺序执行批次，返回值原样保存为 chunk-001.json、chunk-002.json……
# 输出超过 43000 字节会拒绝返回，减小该批 ID 数重试；不丢弃或截断节点。
uxqa figma check --input /path/to/new-capture --out /path/to/new-report
```

使用 Figma MCP 的 `use_figma` 时仍须遵守该连接的技能和会话要求。采集脚本只选择指定页面、读取节点和它们引用的变量。母库变量可能作为子库别名的依赖被只读解析，不扫描母库组件或写入任何变量。每轮 prepare 产生不同 exportId，不能混用旧索引与新批次。

检查拒绝跨页面/文件/采集轮次、重复组件、非法颜色/尺寸、重复主题、缺失主题和空索引。缺失组件会得到 partial；零批次不会通过。JSON 输入限 8 MiB/文件、32 MiB/轮、500 批。输出必须位于采集目录之外，且目录为空；不覆盖已有证据。

## 规则与覆盖

- 文字：按显式主题解析别名、合成透明前景，依据字号/字重计算 4.5 或 3 的阈值。
- 输入边界：按组件名称识别候选，检查描边与内外背景；可能有填充替代边界，因此低值列为 review。
- 交互状态：相同组件集和其余 variant 属性下，比较 hover/pressed/focus 与唯一默认变体。外观指纹包含尺寸、位置、文字、画笔和字形信息；完全相同列为 review，复杂效果无法解析列为未验证。
- 小控件：命名识别的组件边界与命名热区至少 24×24；小尺寸及相交热区需人工判断例外和真实点击绑定。
- 提示：检查图标主组件断链、缺图标及不同 Tone 使用同组图标的候选。向量绘制图标可能需要人工确认。
- 文案：只标记有限的明显占位词，不自动替换；不把“名称”等正常字段名当错误。
- 裁切：文字矩形超出裁切祖先只标为 review，需结合原生截图核对。

禁用变体排除适用性检查。渐变、图片背景、混合文字、分组透明度和复杂效果不猜测；报告列明未验证原因。当前只采集指定页面的原生 COMPONENT；模板和独立实例布局、全状态完整性、键盘/读屏、实际点击、代码复用和产品全流程均不在本命令结论内。

报告为 `figma.json`、`figma.md`、`figma.html`，含节点链接、主题、采集窗口、输入 SHA-256 和逐项状态。`complete` 只表示索引采集齐全；`limited-pass` 也只表示已执行设计规则通过。存在 fail/review/not-verified 或缺失采集时返回 1；输入错误返回 2。HTML 转义所有设计文案并禁用脚本。

该入口是 Figma 设计规则检查，不是 C5b 母子库组件继承/代码替代能力的实现，也未接入控制台来源管理。

## 通用化、变体与产品设计合同

快照同时记录可见层级骨架、嵌套组件依赖、字体和颜色绑定。报告按组件集汇总，并列出跨组件集的同骨架候选；业务目的、数据模型、交互和属性合同仍须人工比较，不能仅因外观相似自动合并。快照不会猜测哪些组件是新增，必须提供可信的创建记录或完整历史索引。

配置可声明 `forbiddenFonts`（字体名前缀数组）、`allowedColorPrefixes`（颜色变量名前缀数组）及 `tokenExpectations`（`{id, theme, expected:[r,g,b,a]}` 数组）。这些是项目合同，不作为所有产品的默认规则。禁用字体/明确色值违约为 fail；未绑定画笔和不匹配前缀为 review，需考虑保留的图标笔触和合法继承。

较大的采集返回可使用无损 `uxqa-json-dictionary-v1` 字符串字典封装，保存原返回即可；check 自动解包并限制单批展开到 2 MiB。不会因输出预算默默截断文本或节点。
